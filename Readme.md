LAB 3 - PERSONAL PORTFOLIO WEBSITE

1. Introduction
This is a simple personal portfolio website made as part of Lab 3.
It gives basic information about the student, skills, projects and contact details.

2. Technologies Used
- HTML: Used to create the structure of the website.
- CSS: Used to add colours, layout, styling and simple animations.

3. Website Sections
- Home: Shows a short introduction.
- About Me: Gives information about Daizy Goyal.
- My Skills: Shows HTML, CSS and JavaScript.
- My Projects: Displays two sample projects.
- Contact Me: Contains a form for entering name, email and message.

4. Other Features
- Navigation links to move to different sections.
- Profile image on the home section.
- Hover effects and simple animations.
- Back to Top link.
- Responsive design for smaller screens.

5. Files Included
- index.html: Main HTML file of the website.
- style.css: CSS file used for design and styling.
- images/profile.jpg: Profile image used on the website.

6. How to Run the Project
1. Extract the ZIP folder.
2. Open the portfolio folder.
3. Double-click on index.html.
4. The website will open in a web browser.

7. Conclusion
Through this lab, I learned how to create a basic portfolio website using HTML and CSS.
I also learned about navigation links, sections, images, forms, styling and responsive design.

Note:
The contact form is only a front-end form. It is not connected to a database or email service.
